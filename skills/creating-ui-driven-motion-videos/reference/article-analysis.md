# Article Analysis Procedure

Complete this before scripting. The output should be compact enough to paste at the top of `STORYBOARD.md`.

## 1. Distill the argument

Write:

```text
Topic:
Thesis:
Viewer takeaway:
Opening tension:
Turning point:
Conclusion:
Audience:
Tone:
Protected terms:
Claims that must not be embellished:
```

Separate the article's main argument from examples and supporting observations. If the article contains several ideas, choose one spine rather than giving every paragraph equal screen time.

## 2. Map the reasoning

Describe the article as a sequence of logical moves, for example:

```text
familiar belief → contradiction → hidden mechanism → consequence → new belief
concrete situation → fragmented evidence → synthesis → audience-specific decisions
surface skill → higher-order skill → AI changes execution → human value moves upward
```

This reasoning map is a source for the script, not a mandatory scene count.

## 3. Find the showable structure

Choose the relationship viewers need to see:

| Relationship | Useful visual behavior |
| --- | --- |
| Transformation | morph, before/after, material passing through stages |
| Hierarchy | layers, elevation, zooming between levels |
| Comparison | split frame, parallel timelines, controlled contrast |
| Network/system | nodes, dependencies, feedback loops, camera traversal |
| Accumulation | fragments collecting into a whole, evidence stacking |
| Translation | one object reformatted for different audiences or contexts |
| Perspective | rotate/reframe the same object, reveal hidden dimensions |
| Learning/adaptation | changing paths, branching attempts, compressed iteration |

Name one governing metaphor and 2–4 supporting visual devices. Avoid metaphors that look appealing but distort the argument.

## 4. Compress into screen language

- Retain only claims necessary to follow the argument.
- Turn explanation into visible change wherever possible.
- Keep exact quotations rare and short.
- Use labels to clarify visuals, not replace them.
- Preserve nuance at the conclusion; do not turn a conditional claim into certainty.

## 5. Analysis gate

Do not proceed until these questions have clear answers:

1. What changes in the viewer's understanding?
2. What relationship can motion reveal better than static prose?
3. Which scene is the conceptual turning point?
4. What single image should remain in memory after the video ends?
5. Why would the Writing Harness pipeline be appropriate or inappropriate here?
