# Narrative and Storyboard Patterns

Patterns are starting points. Choose from the article's reasoning map, combine when useful, and change the number of beats to fit the idea.

## Pattern Library

| Pattern | Best for | Possible beat shape |
| --- | --- | --- |
| Transformation pipeline | tools, harnesses, repeatable processes | raw input → mechanism → stages → artifact |
| Layer reveal | meta concepts, abstraction, hierarchy | concrete layer → pull back → higher layer → implication |
| Fragment to structure | sense-making, articulation, research | fragments → tension → grouping → coherent model |
| Parallel contrast | two approaches, before/after, trade-offs | shared start → split paths → consequences → synthesis |
| One object, many views | translation, stakeholder alignment, perspective | object introduced → rotate/reframe → audience views → whole |
| System journey | dependencies, ecosystems, feedback loops | enter node → traverse links → reveal loop → intervention |
| Repeated pattern | habits, signals, emergent behavior | instance → repetition → pattern recognition → principle |
| Escalating questions | judgment, critical thinking, inquiry | claim → question → deeper question → changed conclusion |

The Writing Harness video uses **transformation pipeline**. It is a strong fit for packaged systems, skills, workflows, and processes. It should not be reused for an article whose argument is better explained by hierarchy, perspective, comparison, or another pattern.

## Example Mappings

- An article about meta skills may use a layer reveal: tool skills on a lower plane, the camera pulls upward to thinking systems that steer them, then AI compresses the lower layer.
- An article about PM articulation may use one object, many views: a blurred problem sharpens into a model, rotates toward Engineering, Sales, and Leadership, then returns as one coherent decision.
- An article about confirmation bias may use escalating questions: evidence cards repeatedly enter a frame until a counterexample breaks the enclosure.
- A writing harness or agent workflow may use the transformation pipeline: loose ideas enter a packaged system of skills, guardrails, and voice, then emerge as an article.

## Anti-Template Check

Before implementation, answer:

- Does the opening arise from this article, or could it introduce any article?
- Is there a governing visual metaphor beyond floating text and cards?
- Does each transition express a relationship in the argument?
- Have prompt bars, file trees, scan rows, processing phrases, output cards, and cursor clicks been included only because the concept requires them?
- Is at least one composition or motion idea meaningfully different from the previous video?
- Could a viewer understand the core relationship with the text muted or reduced?

If three or more scenes could be swapped with the previous video's copy without changing their design, revise the storyboard.
