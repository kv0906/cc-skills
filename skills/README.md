Copy a complete skill folder, including its supporting files. See the [installation guide](../README.md#get-started) and [Amp snapshot sources](../SOURCES.md).

## Bundles and alternative versions

The [explanation bundle](../bundles/explanation-skills/) contains an alternative `explain-to-me`, `asd-ste100`, and `explaining-with-ascii`. Choose either the standalone `explain-to-me` or the bundle's version; installing both into the same destination overwrites one. The two copies of `explaining-with-ascii` are identical.

Some skills require agent-specific tools, software, or accounts. Read the selected skill before installing it; inclusion here does not guarantee that every agent supports its workflow.
